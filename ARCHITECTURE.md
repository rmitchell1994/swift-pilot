# Architectural Decisions

This file records key architectural decisions, the reasoning behind them, and the alternatives that were considered. **When any decision is made — about structure, tooling, patterns, or behaviour — add an entry here.**

Coding agents read this file automatically. Before proposing or implementing anything non-trivial, check this file first.
